# Portafolio Personal - Paul Vásquez («El Flaco»)

Portafolio web desarrollado con **React** y **Bootstrap 5** para la Evaluación Formativa N° 2 de la asignatura Desarrollo Fullstack II (DSY1104).

## 🚀 Características del Proyecto
- **Persona/Estudiante:** Paul Vásquez
- **Framework Front-End:** React.js
- **Diseño Responsivo:** Bootstrap 5 (Navbar, Card, Grid System)
- **Manejo de Datos Dinámicos:** Consumo de archivo JSON local (`/data/noticias.json`) mediante `useState` y `useEffect`.
- **Pruebas Unitarias:** Implementación con Jasmine y Karma con informe de cobertura de código.
- **Accesibilidad:** Cumplimiento de etiquetas `alt` en imágenes y elementos ARIA en componentes interactivos.
